# PRISMA-LSR

For **living systematic reviews** — reviews maintained in a continuously updated mode rather
than published once. Four new items (**L1**–**L4**) plus extra reporting elements attached to
existing PRISMA 2020 items. Base items are in `prisma-2020.md`.

The organising problem is that a living review is a *sequence* of versions, so every claim
needs a version anchor: what triggered this version, what changed since the last one, and
whether the change was applied retrospectively to previously included studies. **L2** and
**L3** exist to force that, including the requirement to state explicitly when *nothing*
changed.

Note also **item 24c of PRISMA 2020 is replaced by L2**, and that PRISMA 2020's optional
element about being a living review becomes *essential* here (item 1).

Cite as `[@akl2024prismalsr]`.

## New items

### Item L1 — Living mode parameters (Methods)

Specify the living mode parameters:

- Specify the planned schedule of the search for each source (eg, at a prespecified interval, following predefined triggers)
- Specify the planned schedules for the remaining steps of the systematic review (eg, at a prespecified interval, following predefined triggers), if applicable. The remaining steps include screening, data collection, risk of bias assessment, analysis, certainty of evidence assessment, publication
- Specify the plan for retirement from the living mode (eg, based on a prespecified timeline, following predefined triggers), if there is one. If there is no such plan, indicate so

### Item L2 — Changes to the methods (Methods)

Describe changes to the methods:

- Describe and justify any changes since the preceding version to the methods (items L1, 5–15)
- If there are no changes to the methods, indicate so
- Indicate whether the changes to the methods were applied to previously included studies

*Replaces PRISMA 2020 item 24c.*

### Item L3 — Changes to the results (Results)

Describe changes to the results:

- Indicate the studies that were included since the preceding version (related to PRISMA 2020 item 17)
- Describe and justify the changes since the preceding version in the eligibility status of any study (ie, excluding a previously included study, including a previously excluded study; related to PRISMA 2020 item 16)
- Describe any other consequential changes since the preceding version to the results
- If there are no changes to the results, indicate so

### Item L4 — Authors and their roles (Other information)

Provide the list of authors and their roles for each version of the LSR.

## Additional elements on existing PRISMA 2020 items

### Item 1 — Title

- Identify the report as "living" in the title. *In PRISMA 2020 this was a non-essential element; in PRISMA-LSR it is essential.*
- Provide the version number

### Item 2 — Abstract

- Indicate whether the LSR is being retired from the living mode after the publication of the current version, if applicable

### Item 3 — Rationale

- Justify the use of the living mode
- Cite the preceding version of the LSR, if applicable

### Item 4 — Objectives

- Describe and justify any changes since the preceding version to the review's objective(s) or question(s)

### Item 9 — Data collection process

- Describe whether the review team updated or planned to update collected data for a previously included study when relevant

### Item 11 — Study risk of bias assessment

- Describe whether the review team updated or planned to update risk of bias information for a previously included study when relevant

### Item 13d — Synthesis methods

- Report any analytical methods applied specifically because of the living mode

### Item 16a — Study selection

- Describe what triggered the current version, if applicable
- Ideally, use a flow diagram to illustrate the results of the search and selection processes in the different versions of the review using one of the LSR tailored flow diagrams

### Item 20b — Results of syntheses

- Report results of any analytical methods applied specifically because of the living mode

### Item 23c — Discussion: limitations of the review processes

- Discuss any limitations related to the living mode

### Item 23d — Discussion: implications

- Describe any changes since the preceding version to the implications of the results for practice, policy, and future research
- Describe and justify any planned changes to review methods in upcoming review versions
- Indicate and justify whether the LSR is being retired from the living mode following the publication of the current version, if applicable

### Item 25 — Support

- Describe the sources of financial or non-financial support and the roles of funders or sponsors in each of the versions of the LSR

### Item 26 — Competing interests

- Describe the competing interests of review authors and how they were managed for each of the versions of the LSR

### Item 27 — Availability of data, code and other materials

- Describe any changes since the preceding version to the accessibility of data, code and materials
